# 📌 AikoAc (AntiCheat) - Guia Completo

## 🚀 Introdução

O **AikoAc** é um sistema anticheat avançado desenvolvido para o **FiveM**, garantindo a segurança e integridade do servidor. Ele oferece ferramentas poderosas para **monitoramento**, **detecção** e **mitigação** de trapaças, além de funcionalidades administrativas para uma gestão eficiente do servidor.

O comando `/aiko` é a principal interface do AikoAc, permitindo que administradores e moderadores executem algumas ações diretamente dentro do jogo.

> ⚠️ A maioria das funcionalidades administrativas agora são realizadas diretamente pelo **Painel Administrativo Web**, que oferece uma interface mais completa e segura para gerenciamento do servidor.

---

## 🔹 Subcomandos Disponíveis

### 🎯 1. **info**

Exibe informações detalhadas sobre o jogador que executou o comando.

### 📋 2. **menu**

Abre o menu do sistema AikoAc para o jogador (requer permissão adequada).

### 👑 3. **setowner \[id]**

Define um jogador como dono do servidor (executado **exclusivamente via console**).

### 🎫 4. **unban \[id]**

Remove o banimento de um jogador no servidor (executado **exclusivamente via console**).

---

## 🔑 Permissões

Cada subcomando exige um nível específico de permissão:

* **👑 owner** - Dono do servidor
* **🔧 admin** - Administrador
* **🛡️ mod** - Moderador
* **📞 sup** - Suporte
* **🎮 user** - Jogador comum

---

## 📌 Observações

✔️ O AikoAc **detecta atividades suspeitas em tempo real** e pode tomar ações automáticas para impedir trapaças.
✔️ A maioria dos comandos administrativos foi migrada para o **Painel Administrativo**.
✔️ Os comandos `setowner` e `unban` devem ser executados diretamente no **console do servidor**.
✔️ O comando `/aiko` sem parâmetros exibirá os comandos disponíveis no jogo.
